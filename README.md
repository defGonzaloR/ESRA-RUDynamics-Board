# ESRA-RUDynamics-Board

<img width="446" height="444" alt="ESRA_PDB_Gonzalo" src="https://github.com/user-attachments/assets/e6ccf14f-9f40-4c8a-a40f-abbb50b4871c" />

This is V3 of the Rutgers Dynamics power distribution board, building off of the original board designed by the Columbia University Robotics team. This is also my first power distribution board design. 

I used a board-mounted XT90 connector to attach to the Lipo batteries. For circuit protection, I included fuse holders that connect to each output for the legs, as well as essential filtering for high-noise signals. At the bottom is a buck converter, to step down the 24V to 12V for powering the Jetson Orin Nano.

Due to funding, this board was discontinued, but I'm excited to apply skills and theory learned from this design to future applications.
